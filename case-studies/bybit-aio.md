# Bybit AIO
### Автоматизация операций с аккаунтами криптобиржи

**Коммерческий продукт для клиентов · 2024**

В рамках работы разработал приложение для управления несколькими аккаунтами Bybit. Оно объединяет панель учёта, интерактивную консоль, интеграцию с REST API и браузерные сценарии.

**Моя роль:** разработка приложения, интеграций и модулей автоматизации.  
**Стек:** Node.js · JavaScript · Playwright · REST API  
**Интеграции:** AdsPower · Notion API · IMAP · TOTP · 2captcha  
**Исходники:** закрыты.

## Задача

Клиентам требовалось выполнять повторяющиеся операции для нескольких аккаунтов: регистрировать и настраивать аккаунты, участвовать в промоакциях, торговать, проверять балансы и выводить средства.

Каждая операция использует связанные данные: браузерный профиль, почту, прокси, API-ключи и параметры аккаунта. Нужно было объединить их и автоматизировать действия, которые выполняются через разные интерфейсы биржи.

## Что я разработал

**Панель учёта аккаунтов.** Настроил связанные таблицы аккаунтов, почты и прокси в Notion и подключил их к приложению через API. Панель позволяет выбирать аккаунты для обработки, просматривать состояния и балансы.

**Интерактивную консоль.** Реализовал выбор операций, аккаунтов и параметров: торговой пары, сети, типа счёта и других настроек. Через один интерфейс пользователь запускает задачи и получает результаты выполнения.

**Модули операций.** Реализовал регистрацию, участие в промоакциях, торговлю, получение депозитных адресов, внутренние переводы, добавление адресов в список разрешённых для вывода и вывод средств. Дополнительно — получение API-ключей, настройку 2FA, обновление информации об аккаунтах и сбор балансов.

## Ключевые технические решения

### Объединение API и браузерной автоматизации

Для балансов, депозитных адресов и внутренних переводов реализовал подписанные запросы к REST API Bybit.

Для регистрации, настроек аккаунтов и вывода — браузерные сценарии на Playwright. Торговые операции поддерживают оба способа.

Оба варианта доступны через общую консоль: пользователь выбирает задачу и параметры, а взаимодействие с биржей выполняет соответствующий модуль.

### Работа с контекстом каждого аккаунта

Интегрировал приложение с AdsPower: Playwright подключается к запущенному браузерному профилю и работает с его cookies и сохранённой сессией.

Связал аккаунты с профилями, почтой и прокси. В сценарии используется контекст выбранного аккаунта, включая данные для авторизации и подтверждений.

Подключил получение почтовых кодов через IMAP, генерацию TOTP-кодов и внешний сервис решения CAPTCHA.

### Обработка нескольких аккаунтов и результаты

Реализовал запуск операций для выбранной группы аккаунтов. Для ряда задач предусмотрены задержки и повторные попытки, а этапы выполнения и ошибки выводятся в логи.

Результаты получения балансов и депозитных адресов выгружаются в CSV и Excel. Отдельные данные аккаунтов обновляются в панели через Notion API.

## Пример работы

Добавление адреса в список разрешённых для вывода:

1. Пользователь выбирает операцию, аккаунт и сеть.
2. Приложение запускает соответствующий браузерный профиль и выполняет сценарий.
3. В консоли отображаются этапы работы и результат добавления адреса.

## Результат

Разработанное приложение использовалось как коммерческий продукт для клиентов.

Клиент мог подготовить данные в панели, запустить операцию для выбранных аккаунтов и получить результаты в логах и отчётах. Повторяющиеся действия с биржей выполняли модули приложения.

Пополнение оставалось отдельным этапом: Bybit AIO получал депозитные адреса, а рассылку средств выполнял внешний инструмент на выбор клиента.
